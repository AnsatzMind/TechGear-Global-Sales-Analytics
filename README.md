
# TechGear Global | Retail Sales Analytics Dashboard

### Power BI | DAX | Power Query | Excel | Data Visualization

## Project Overview

TechGear Global is a retail sales analytics project developed using Microsoft Power BI to explore business performance across stores, products, customers, and sales periods.

The project uses historical sales data from **2023 and 2024** to examine revenue trends, profitability, product performance, customer behavior, sales targets, and product returns.

The objective is to transform transactional retail data into interactive business intelligence reports that support data-driven decision-making.

## Business Objectives

- Analyze overall sales and revenue performance.
- Track important business KPIs and profitability trends.
- Compare sales performance across different periods.
- Explore product-level sales distribution.
- Evaluate store performance against sales targets.
- Examine product returns and associated reasons.
- Present business information through interactive Power BI dashboards.

## Dataset Description

**Source:** `TechGear_retails.xlsx`

The Excel workbook contains the following datasets:

| Dataset | Description |
|---|---|
| Sales_2023 | 4,000 sales transactions from 2023 |
| Sales_2024 | 5,000 sales transactions from 2024 |
| Customers | Customer details, countries, cities, and segments |
| Products | Product names, categories, subcategories, and standard costs |
| Stores | Store information, regions, countries, and sizes |
| Store_Targets | Monthly store sales targets for 2024 |
| Returns | Returned orders and return reasons |

The workbook also contains a dataset overview sheet.

### Dataset Highlights

- **9,000 sales records** across two years
- **500 customer records**
- **124 product records**
- **6 stores**
- **500 return records**

## Dashboard Features

The Power BI report contains two report pages, featuring multiple forms of business analysis.

### 1. Performance Dashboard

The report includes visuals for monitoring important sales and business metrics, including:

- Revenue-related KPI indicators
- Profit trends
- Sales quantity distribution
- Gauge and funnel visualizations
- Line charts for performance analysis
- Summary cards for key metrics

### 2. Detailed Analytics Dashboard

The second report page uses additional analytical visualizations, including:

- Line charts
- Waterfall chart
- Combined line and column chart
- Stacked area chart
- Interactive slicer

These visuals support exploration and comparison of retail performance across different dimensions.



## Project Workflow

1. **Data Collection:** Used the Excel workbook containing sales and supporting business datasets.
2. **Data Preparation:** Prepared the source tables for retail sales analysis in Power BI.
3. **Data Modeling:** Organized related datasets for multidimensional reporting.
4. **Dashboard Development:** Built report pages containing business KPIs and analytical visualizations.
5. **Business Analysis:** Explored sales, product, profitability, and performance trends.
